# Lien GitHub → site

son contenu s'affiche en haut de https://github.com/TKonate.

Pour que le profil GitHub renvoie vers le site, remplacer le contenu de
`TKonate/TKonate/README.md` par le bloc ci-dessous (adapter la bio si besoin).
